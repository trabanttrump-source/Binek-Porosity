Version 2.5 (Legacy Edition)

Overview
Binek 2.5 is a professional, standalone image analysis application designed for materials science, metallography, and quality control laboratories. It provides a complete toolkit for porosity analysis, length measurements, hardness testing (Vickers & Knoop), and comprehensive reporting – all in a single, portable executable file.

Key Capabilities
Image Processing
Real-time brightness, contrast, and gamma adjustment

Gaussian, median, and bilateral filters

Erosion and dilation (morphological operations)

Color and grayscale display modes

12 Binarization Methods
Type	Methods
Manual	Manual Range (user-defined thresholds)
Global	Otsu, Triangle, Yen, Li, IsoData, Minimum
Adaptive	Single-scale, Multi-scale, Adaptive Otsu (local blocks)
Advanced	Watershed, Multi‑Otsu, Fusion Voting (5 methods ensemble)
Regions of Interest (ROI)
Up to 5 ROIs per image

Shapes: Rectangle, Ellipse, Polygon, Freeform

Independent binarization settings per ROI

Automatic porosity calculation per region

Measurements
Length: 3 independent series with statistics (mean, std dev)

Hardness: Vickers (HV) and Knoop (HK) with custom loads

Porosity: Percentage, pore size distribution (5 categories), histograms

Output & Reporting
Colour‑coded fusion images with customisable legend

Word (DOCX) and Excel (XLSX) reports with tables and annotated images

Project files (.binek) – save complete analysis state

Export individual images (PNG, JPG, TIFF)

Additional Features
Camera support: Live preview and capture from DirectShow cameras

Multi‑image clipboard: Load, paste, and manage multiple images

Calibration: Pixel‑to‑real‑world (µm, mm, in) with scale bars

Undo/Redo: Full support (Ctrl+Z/Y)

Customisable: Colours, line widths, fonts, legend appearance

Keyboard shortcuts for efficient workflow

System Requirements
OS: Windows 10/11 (64‑bit)

RAM: 4 GB minimum (8 GB recommended)

Storage: 200 MB free space

Display: 1280 × 720 minimum

Camera: DirectShow‑compatible (optional)

Quick Start Workflow
text
1. Load image (Ctrl+O) → 2. Adjust brightness/contrast
3. Calibrate (draw known length) → 4. Select binarization method
5. Compute porosity → 6. Add ROIs (optional)
7. Measure lengths / hardness → 8. Generate report
9. Save project (.binek)
